```
index.html       Home: intro, about, projects grid, engineering project details, contact
quickbite.html   QuickBite case study
styles.css       All styles (light + dark theme)
theme.js         Light/dark toggle
img/             Screenshots and figures (WebP)
```

## 1. Contact links

Already filled in (Contact section of `index.html`): LinkedIn, GitHub (`mahteb`) and email.

## 2. Publish free on GitHub Pages

1. Sign in to GitHub as `mahteb`.
2. Create a new **public** repository named exactly `mahteb.github.io`.
3. Upload every file and the `img` folder from this folder (Add file → Upload files → drag them in → Commit).
4. Repository **Settings → Pages**: Source = "Deploy from a branch", Branch = `main`, folder `/ (root)` → Save.
5. After 1–2 minutes the site is live at **https://mahteb.github.io** — put that link on your CV (and on your LinkedIn profile if you ever want to; nothing is posted there automatically).
